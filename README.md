# Utility Forge

A static, client-side collection of generators and file utilities designed for GitHub Pages.

## Included
Receipt, invoice, quote, password, business card, keycard, percentage, unit, timesheet, filename, random, color/CSS, JSON, CSV, text, QR payload, labels, file, image, and audio/video recording tools.

No backend is required for the included tools. Local history uses browser localStorage.

## GitHub Pages
Put these files in a repository and enable GitHub Pages from **Settings → Pages**. GitHub Pages can publish static HTML/CSS/JavaScript directly from a repository. See the official documentation:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Privacy
The generators operate in the browser. The site does not contain a password collection endpoint or analytics backend.
